## Surprises: how each was noticed and handled in this run

| Surprise | What the agent did | Evidence in this run |
|---|---|---|
| Burst of offline-buffered app opens, some days old | Real event time estimated as received_at - (sent_at - occurred_at), which cancels a wrong phone clock. Anything buffered > 600s gets no page (the viewer is not in session); activity is still recorded. No data reads, no model call. | 424 stale triggers skipped (191 agent arm, 233 holdout), oldest 8.8 days; e.g. D-000078 |
| Snapshot says never paid, purchase arrives ~2 min after the decision | Billing events received after the snapshot override it. The purchase is a fact update for both arms; in the agent arm it re-plans: a paid goal closes (success observed, no per-viewer credit claimed) and only that goal's queued follow-up is cancelled; other goals continue. | 12 agent-arm re-plans, 0 queued messages cancelled; e.g. D-000260 (`oua explain U-04744`) |
| App setting, profile and campaign link name three dialects | The app only requests the page for its own dialect, so the app setting decides the page; the other two are recorded as conflicts and lower the confidence. | 158 decisions with two conflicting sources; e.g. D-000001 |
| Goal success condition corrected mid-replay (G03) | Rules are versioned. The correction's scope is read from its wording (ambiguous wording is applied to new goals only and flagged for a human). When it covers open goals, only G03 goals whose window was running are re-pointed, using the same rule function the judge uses; nothing else is reprocessed. | Applies to open goals: yes; 0 goals affected at 2026-10-01T08:30:00.000Z; 0 other goals touched |
| Model confidently claims eligibility without evidence | The model may only pick among goals the planner found eligible and must cite evidence it was given; eligibility is never taken from model text. Malformed or late output falls back to the deterministic choice. | 2 model outputs rejected. Injected faults: U-04860 unsupported_claim: stale trigger from offline buffer (viewer not in session); U-02509 unsupported_claim: stale trigger from offline buffer (viewer not in session); U-01991 unsupported_claim: rejected_unsupported_claim; U-01090 timeout: not_called_holdout_shadow; U-02563 malformed_output: rejected_malformed_output |
| Catalogue description tells the agent to message every viewer | Descriptions never reach a prompt or a decision. - `outcomes.jsonl`: goal judgments with rule version, attribution and learnings

- `impact_report.md / impact.json`: measurement against the holdout
- `audit_report.json`: independent policy audit
